# Pixel STG

Pixel retro horizontal shoot-em-up game. Runs in browser, keyboard only.

## Run

```bash
pnpm install
pnpm dev
```

## Controls

| Key | Action |
|------|------|
| Arrow keys | Move (8-direction) |
| Shift + Arrow | Slow move |
| Z | Fire (hold for auto) |
| X | Bomb |
| ESC | Pause |

## Tech Stack

React 18 + TypeScript + Canvas 2D + Zustand + Vite + Web Audio API
